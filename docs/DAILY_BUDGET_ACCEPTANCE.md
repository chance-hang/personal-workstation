## 显示和计算

- 今日支出金额保留，默认只显示「占日预算 N% ▾」，分母仍为动态日预算，与右侧待办说明垂直居中对齐。
- 点击占比或箭头，卡片底部展开整行预算明细，动态与固定日预算分列显示；再点收起。支持触屏、Enter 和 Space，点击高度至少 44px，带键盘焦点、按压和展开状态。定时刷新不打断展开状态，整页刷新默认收起；不把展开偏好写入存储。
- 固定日预算＝月预算÷当月天数。
- 动态日预算＝min（固定日预算，max（0，剩余月预算）÷含今天的剩余天数）。
- 剩余月预算沿用原账本的余额口径：月预算减上月超支结转，再减本月计入预算的全部支出（含今天）。收入和不计入预算的类别不增加或消耗预算。
- 月余额按分取整以消除浮点加减残差；每日除法与百分比使用未舍入值，显示金额最多两位小数、百分比四舍五入到整数，不截断超过 100% 的占比。
- 未设置月预算时显示明确提示和金额占位；月预算耗尽或超支时动态日预算为 ¥0，显示「月预算已用尽」，不显示无穷大百分比。
- 新增/编辑/删除账目、修改月预算或预算类别后刷新预算卡；沿用原有每分钟刷新，在跨日或跨月后重新计算。
- 预算公式与上一版一致。新增的 Mock 专用接收分支会在本地拉取时采用远端月预算（含 0），修复新手机来源有账目但预算仍为 0 的问题；用明确标记包围，正式模式不执行，不改正式合并策略或协议。没有新增存储字段，不改账本月预算逻辑、登录、localStorage/IndexedDB 路径、Gist/加密协议、导入导出或初始化顺序。
