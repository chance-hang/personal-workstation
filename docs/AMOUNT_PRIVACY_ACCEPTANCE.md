# 金额隐私验收

在页面右上点击「金额隐私」。按钮显示「金额已隐藏」时，首页、账本、预算、资金规划、资产负债和历史中的金额显示为固定占位符。按金额计算的预算比例、储蓄进度和金额图表也会隐藏。再点一次恢复显示。

- 刷新和同一浏览器下的标签页沿用当前设置。设置保存在当前浏览器，其他设备可独立切换。
- 隐私开启时，记账、金额编辑、速记录入和完整备份导出需先关闭隐私。日报和历史记录可下载遮盖后的 Markdown。四象限和学习大纲导出也会遮盖能识别的金额文字。
- 自由文本会遮盖 `¥1200`、`预算：1200`、`1.2 万元` 等有金额线索的写法。脱离语境的裸数字可能仍然显示，例如一条仅写有 `1200` 的待办。
- 这是界面显示设置。保存、备份和同步仍使用原始账目，已下载的文件不会随开关变化。

## 验证

使用临时 Edge 浏览器和 4197 端口的本地 Mock 验证。用例覆盖开关、跨标签页、刷新、原始账目与备份结构、报告遮盖和 320 至 1440 像素窗口。模拟数据只在测试上下文使用。

```powershell
$env:PORT='4197'
$env:MOCK_PREVIEW_ONLY='1'
$env:MOCK_BIND_HOST='127.0.0.1'
node tools/mock-sync-server.mjs
```

另开终端运行 `node tools/check-amount-privacy.cjs`，需可加载 Playwright。没有 Playwright 随附浏览器时，可用 `QUADRANT_BROWSER` 指定 Edge 或 Chromium 的可执行文件。
