# 存款记录需求（2026-11-18）

## 已确认范围

来源：用户在本聊天提出需求并回答两轮问题。

- 在工作台账本模块中增加存款记录，支持按月、按年统计查询。
- 同时记录存取流水和历史月份余额。
- 分账户管理，账户可自行添加，例如现金、银行卡、微信和支付宝。
- 与现有日常收支独立：记录存款不自动生成收入、支出，不自动扣改旧账本数据。
- 首版不含投资、理财、基金和负债。

## 拟采用的记录与统计规则

以下为根据已确认范围提出的实现细节，尚未完成界面验收。

- 账户保存名称、起始日期、起始余额；不需要完整银行卡号。
- 流水保存业务日期、账户、存入/取出类型、金额、备注；可补录和修改。
- 账户互转同时关联转出、转入账户。单账户可查询转入、转出；全部账户统计时互转相抵，不算新增存款或取出。
- 余额由起始余额和截至查询日期的有效流水计算。起始余额单独展示，不计入当月或当年净存入。
- 月度展示期初余额、期间新增起始余额、存入、取出、净存入、互转净额和期末余额。账户于当月建立时，新增起始余额单列，避免误显示为本月存入。
- 年度按相同口径汇总，并列出各月数据；余额不能把各月余额直接相加。
- 支持全部账户和单账户筛选，以及查询历史年月。
- 尚未开始记录的历史期间显示未记录，不捏造零余额；无流水但已有余额的期间延续余额。
- 金额以分为单位计算，展示为人民币元，避免小数累加误差。
- 负余额、流水早于账户起始日期、互转到同一账户、无效日期等情况需要明确校验。
- 补录或修改历史流水后，相关后续余额重新计算；不生成不可解释的余额修正。
- 已有流水的账户优先停用并保留历史，避免删除账户后流水失去归属。
- 遵循工作台现有金额隐私开关、数据保存、加密同步及 JSON 备份体系。只增加存款业务字段及必要合并规则，不更换原有存储路径和加密协议。
- 不把资金规划里的旧资产金额或目标完成值自动迁入新存款记录；它们不是有明确起始日期的存款流水。
