## 审计要点

- 重要、紧急、计划分钟与计划日期独立；旧待办保持未分类。用时不从创建/完成间隔推算。
- 实际投入逐段保存发生日、首次录入日/时间、象限快照及临时标记；改当前分类不改历史快照。计划用时、番茄休息和文本日志不会混入实际投入。
- 用时按 ID 合并，同日复盘按日期 ID 合并，较新版本胜出，删除保留标记；任务正文与时间计划分别合并。双向合并结果一致，旧远端缺少新增集合时保留本机记录。
- 保存、localStorage、IndexedDB 镜像、JSON 备份/覆盖/合并导入及 Mock 同步保留新增信息。仅增加兼容字段，原登录/账户、键名、存储路径、Gist/加密协议、初始化及备份外层格式保留。
- 检查日期和分钟有效性、任务已删除/编辑期间收到更新、导出转义、未记录状态与回顾补记，不生成虚构工时和效率指标。
- 四格尺寸与轴线中心一致，默认未完成包含未排期任务；手机选择象限后操作全宽任务列表，切换栏/工具栏/看板边界一致。
