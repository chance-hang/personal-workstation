# 待办开始日期验收

从首页或事项列表新建待办时，计划开始默认今天，可清空。计划完成不能早于计划开始。旧任务继续保留开始日期空缺，可在详情补填。

- 四象限默认按开始日期查看。已到开始日期的任务持续展示至完成，未来任务可提前选日期查看。实际开始早于计划开始时，以实际开始记录参与展示。
- 任务状态为待开始、进行中、已完成。点击「开始任务」可在 0% 时进入进行中。首次录入部分进度时记录首次开始时间。进行中超过计划完成日期时提示超出计划天数。
- 详情展示实际开始时间和进度变更记录。首页、列表和四象限复用同一个待办。进度达到 100% 标为已完成。
- 四象限历史日期显示截至该日最后一次记录的状态与进度，过去缺少进度记录时显示未记录。历史看板的完成勾选停用，可打开详情查看和维护当前事项。
- 开始日期与实际用时独立。手工工时仍需录入。JSON 备份保存开始与进度字段，区间 Markdown 增加开始日期及进度记录。

计划、任务名称及重要紧急分类继续使用当前值，历史进度使用已保存的变更记录。修改计划日期会改变计划查询归属。历史记录从功能启用后的真实操作开始保存。

验证使用临时浏览器与独立本地 Mock，不使用真实账号或业务数据。运行 `node tools/check-task-start.cjs`，需要可加载 Playwright，可通过 `QUADRANT_BROWSER` 指定 Edge 或 Chromium。脚本使用 4209 端口，退出后停止其模拟服务。

本地验收预览为 http://127.0.0.1:4208/?mockSync=1 。
