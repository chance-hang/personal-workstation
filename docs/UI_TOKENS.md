# 工作台控件令牌

当前事项 UI 继承 `styles.css :root` 的现有系统字体、黑灰配色、模块语义色和圆角，并补齐以下通用控件令牌。首页事项录入、事项列表、筛选和详情共同使用。

| 用途 | 令牌 | 当前值 / 来源 |
| --- | --- | --- |
| 内容字号 | `--ui-font-body` | 14px，与日志正文一致 |
| 辅助正文 | `--ui-font-small` | 13px |
| 标签 / 辅助说明 | `--ui-font-caption` | 12px |
| 状态徽标 / 数量 | `--ui-font-micro` | 11px |
| 卡片 / 详情标题 | `--ui-font-heading` | 16px，字重 `--ui-weight-heading:600` |
| 桌面输入 | `--ui-font-control` | 14px |
| 触屏输入 | `--ui-font-touch` | 16px，粗指针设备上供输入框使用 |
| 统一输入高度 | `--ui-control-height` | 44px，日期、时间、选择器、保存按钮等高 |
| 点击区域 | `--ui-hit-size` | 44px |
| 完成框显示尺寸 | `--ui-check-size` | 20px，细线 SVG 图标，外侧仍有 44px 点击区域 |
| 完成框圆角 | `--ui-check-radius` | 5px，与原待办小勾选框一致 |
| 输入圆角 | `--ui-control-radius` | 现有 `--r-sm` |
| 输入背景 / 边框 | `--ui-control-bg` / `--ui-control-border` | 现有 `--card-soft` / `--line` |
| 基础间距 | `--ui-space-1/2/3/4` | 4 / 8 / 12 / 16px |

颜色继续由 `--text`、`--text-2`、`--card`、`--bg2`、`--line`、`--ok`、`--bad` 等现有令牌提供。其他成熟模块保留现有效果，后续控件维护可逐步引用这些共用语义令牌。

## 控件约定

- 小图标与点击区域分开：完成图形保持轻量，不把整个 44px 点击范围涂成实色。
- 同一表单行使用同一高度，类型选择与保存按钮按底边对齐。
- 日期/时间保留原生输入，显式设定尺寸、字体、边框及 WebKit 值区样式；触屏字号取 16px。
- 搜索标签固定为单行，输入区域可收缩；小屏通过栅格换行布局，不挤压文字。
- 列表详情/删除采用文字操作，保留可点击范围、键盘焦点和按压反馈。
- 继承工作台样式时检查选择器优先级，确保通用 `.card h3` 不覆盖分组辅助字号。
- 本地模拟环境标识持续可见，UI 精修不影响模拟/正式的环境区分。

本轮桌面与触屏布局已在 Chromium 自动检查并查看渲染图；iOS Safari / 企业微信原生日期选择器、系统键盘和真实手指操作仍需真机验收。
