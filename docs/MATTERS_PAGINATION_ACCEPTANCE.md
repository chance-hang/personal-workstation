# 事项列表分页 · 本地验收

状态为待验收。分支为 review/matters-pagination，基线为正式 v3.26.0 的 a23fbed。

打开[本机模拟预览](http://127.0.0.1:4196/?mockSync=1)，点击底部「事项」进入事项列表。预览使用独立来源和模拟同步，可添加测试事项。

- 默认打开「未完成」，并把它放在首位。首页「今日与逾期」的快捷入口仍打开「今日」。
- 「备忘」中未归档排在已归档之前，每页按已有内容分组。「全部」继续按未完成优先排序，保留已关联备忘去重行为。
- 五个视图每页最多 10 条。搜索和筛选作用于全量匹配，再回第一页。最后一页因操作而缩减时自动回到有效页。新建事项与备忘转待办定位到记录所在页。
- 事项详情、筛选含义、首页待办统计、四象限和存储/同步沿用原规则。没有数据迁移。

验证使用独立 Mock、临时 Chromium 及合成数据。运行 tools/check-matters-pagination.cjs 验证五个视图、备忘分组、全量搜索、末页缩减和 320/390px 触屏翻页。四象限专项与事项、备忘转换的既有运行时回归也已复跑。iOS 真机未复测。
